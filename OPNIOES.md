# Opiniões e Respostas

## Qual tecnologia de comunicação o servidor de cálculo utiliza?
Sockets TCP/IP (Java Socket)

## Qual protocolo de mensagem o servidor de cálculo utiliza?
JSON-RPC (Remote Procedure Call baseado em JSON)

## Qual tecnologia de comunicação o servidor de dados utiliza?
RMI (Remote Method Invocation)

## Qual estilo arquitetural o projeto web api implementou para expor suas funcionalidades?
REST (Representational State Transfer)
